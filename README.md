# Ship Your Spring Boot MVP

Your Spring Boot app works on localhost.

That doesn't mean it's ready to ship.

**Ship Your Spring Boot MVP** is a practical pre-launch checklist designed to help developers catch common deployment, configuration, security, and production-readiness issues before going live.

## Who is this for?

This is for you if:

- You built a Spring Boot MVP
- You used ChatGPT, Claude, Copilot, Cursor, or other AI tools while building it
- The application works locally
- You're preparing to deploy it
- You're wondering: "What did I forget?"

## What you get in the Free Edition

- [15 Critical Spring Boot Ship Blockers](checklist/15-ship-blockers.md)
- A simple pre-launch checklist
- [AI-assisted Deployment Blocker Review Prompt](prompts/deployment-blocker-review.md)
- A basic ship-readiness score

## Quick Start

1. Open the [15 Spring Boot MVP Ship Blockers](checklist/15-ship-blockers.md)
2. Check your project against each item
3. Run the [Deployment Blocker Review Prompt](prompts/deployment-blocker-review.md) against your codebase
4. Fix critical blockers
5. Deploy
6. Run a final smoke test
